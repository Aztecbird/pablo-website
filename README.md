# I AM Meditation App - Installation Guide

These instructions guide you through installing the **I AM Meditation** app on your Android device using the direct APK link.

## 📲 How to Install:

### 1. Download the File
Tap on the **`I_AM_Meditation.apk`** download link on the website to download the file directly onto your phone.

### 2. Open & Install
* Tap the downloaded file in your notification bar or file manager.
* A message will pop up asking: *"Do you want to install this application?"*
* Tap **Install**.

---

## ⚠️ Common Security Popups (How to bypass):

### 1. If you see "Blocked by Play Protect" (Very Common)
Because this is a private app that is distributed directly rather than through the official Google Play Store, Android's built-in scanner will show a warning:
* **Do NOT tap "OK"** (that will cancel the installation).
* Tap the small text that says **"More details"** or **"Details"** (usually has a drop-down arrow).
* Tap **"Install anyway"**.

### 2. If you see "Install from Unknown Sources"
Your phone might state it is not allowed to install apps from your web browser, file manager, or chat app:
* Tap **Settings** on that popup.
* Toggle the switch next to **"Allow from this source"** (or *"Allow Unknown Sources"*) to **ON**.
* Tap the back button, and then tap **Install**.

---

### 🧘‍♂️ Open & Meditate!
Once the installation finishes, tap **Open**. The app will be placed directly on your phone's home screen ready to use! Enjoy your cards, loopable music, and full-screen screensavers! ✨
