# Pablo Arellano — website

Upload everything in this folder to the root of your GitHub repository (keep the `assets` and `uploads` folders as they are).

## Turn it on
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
After about a minute the site is live at `https://YOUR-NAME.github.io/REPO-NAME/`.

## Custom domain (pabloarellano.org)
Settings → Pages → Custom domain → `pabloarellano.org` → Save, then add the DNS records GitHub shows you at your domain provider.

## Update the 4 upcoming live concerts
1. Click `concerts.json` → ✏️ Edit.
2. Change only the text inside the quotes (day, date, time, title, link).
3. Commit changes. The site updates in about a minute.
